
# WEBD 1000 — Website Development

Student Workplan · Fall 2026 · Weeks 1–15

Instructor: Davis Boudreau
Delivery: September 9 – December 16, 2026
Course focus: Planning, designing, developing, testing and publishing accessible, responsive websites using HTML5, CSS3, Git and GitHub.

## Course overview

In this course, you will learn how to build websites from the ground up. You will begin by evaluating existing websites and planning your own, then develop semantic HTML pages, style them using CSS, create responsive layouts, and test your work for usability and accessibility.

Throughout the semester, you will complete guided workshops in your existing course GitHub repository and develop an independent website project in a separate repository.

## Semester website project

Students progressively develop an independent website through seven milestones and a final published submission.

| Milestone     | Deliverable                                           |
| ------------- | ----------------------------------------------------- |
| M1            | Project Brief                                         |
| M2            | Sitemap and Wireframes                                |
| M3            | Semantic HTML Website                                 |
| M4            | CSS Implementation                                    |
| M5            | Responsive Implementation                             |
| M6            | Cross-Device Testing                                  |
| M7            | Accessibility and Validation                          |
| Final Project | Complete Responsive Website published on GitHub Pages |
