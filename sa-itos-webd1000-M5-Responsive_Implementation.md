# WEBD 1000 — M5: Responsive Implementation

**Due:** Week 10 (exact deadline in Brightspace)  
**Course:** WEBD 1000 — Website Development  
**Instructor:** Davis Boudreau  
**Assessment type:** Semester Website Project checkpoint  
**Rubric:** 100 points; course weighting to be determined within the 40% Projects and Milestones category.

### Project standards

- Create **one separate GitHub repository named for your website idea**, using lowercase words separated by hyphens (for example, `cape-breton-travel-guide`). Do not use a generic name such as `webd1000-project`.
- Use **Figma for all visual planning and design**. Share a viewable Figma file or page with the instructor; verify that the instructor can open it.
- Keep the website source in the project GitHub repository, separate from your existing WEBD 1000 workshop repository. Maintain meaningful commits throughout development.
- Publish the website using **GitHub Pages starting at M3**. Keep the Pages URL working for subsequent checkpoints. The site should be publishable from the repository's main branch root (or another correctly configured supported source).
- Submit links through Brightspace. Do not submit a ZIP in place of the required live links unless the instructor directs otherwise.

### Purpose

Ensure the website remains usable at different viewport widths.

### Required work

1. Implement responsive navigation suitable for narrow screens.
2. Use flexible sizing, media queries and responsive Flexbox/Grid layouts where needed.
3. Ensure text, buttons, images and cards fit without unwanted horizontal scrolling.
4. Test at approximately 320px, 375px, 768px and 1280px viewport widths.
5. Update Figma mobile/desktop frames to reflect the final responsive decisions.

### Submit to Brightspace

Figma shared page URL, GitHub repository URL, and working GitHub Pages URL. Include a short list of viewport widths tested.

**Before submitting:** Open each link in a private/incognito browser window to verify instructor access.
