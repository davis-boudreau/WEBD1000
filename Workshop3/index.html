Small steps. Useful skills.

Start small. Build something useful.

Learn how clear content, thoughtful layout and a few shared styles can turn a simple page into a welcoming website.

Explore the essentials

Three essentials for your next website

Begin with these foundations, then practise by making one small change at a time.

01 / Structure

Give content meaning

Use headings, sections and navigation to help people understand the page and find their next step.

02 / Layout

Let the layout adapt

CSS Grid gives these cards a shared structure. Resize the page to see columns respond to the available space.

03 / Usability

Make the basics easy

Write useful labels, keep text readable and provide visible keyboard focus. Review your page at narrow and wide widths.

Choose the right list for the content

Use an unordered list for a collection, an ordered list for a sequence, and a description list for terms and explanations.

What to include

  • A clear page heading
  • Useful navigation labels
  • Readable text and visible focus

A simple workflow

  1. Write a short project brief.
  2. Group the content in a sitemap.
  3. Sketch, build and test the page.

Useful terms

HTML
Describes the meaning and structure of content.
CSS
Controls presentation and responsive layout.
Sitemap
Shows how pages and content groups relate.
