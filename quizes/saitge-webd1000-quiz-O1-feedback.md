**1. Which principle helps guide a user’s eye to the most important content first?**
a) Balance
*b) Visual hierarchy
c) Repetition
d) Alignment

💡 **Background:** Visual hierarchy arranges elements to show importance through size, color, contrast, or placement.
🧠 **Feedback:** *Visual hierarchy* helps users scan content naturally, leading the eye from key messages to details. Balance and alignment help layout structure but don’t control attention flow.

**2. What is the main purpose of white space in web design?**
a) To fill unused space with graphics
b) To reduce scrolling
*c) To improve readability and focus attention
d) To increase text density

💡 **Background:** White space (or negative space) separates elements, creating breathing room.
🧠 **Feedback:** *White space* reduces cognitive load and improves readability by grouping related items visually. Crowding elements together harms accessibility.

**3. Which font pairing is most accessible for body text and headings?**
a) Script and cursive fonts
b) Decorative display fonts
c) All-caps serif fonts
*d) Sans-serif for body, serif for headings*

💡 **Background:** Serif fonts help anchor headings; sans-serif fonts improve screen readability.
🧠 **Feedback:** *Sans-serif for body* and *serif for headings* ensure visual contrast and comfort on digital screens. Decorative or all-caps text should be used sparingly.

**4. What contrast ratio meets WCAG 2.1 AA for normal text?**
a) 2 : 1
b) 3 : 1
*c) 4.5 : 1
d) 7 : 1

💡 **Background:** The Web Content Accessibility Guidelines (WCAG) define minimum color contrast ratios for readability.
🧠 **Feedback:** *4.5 : 1* ensures legibility for most users; larger text can meet 3:1, but smaller text requires higher contrast.

**5. The purpose of consistent navigation placement is to ___.**
*a) help users predict where to find links on every page*
b) increase visual variety
c) make the page look modern
d) minimize code size

💡 **Background:** Consistency supports recognition and reduces user frustration.
🧠 **Feedback:** Keeping navigation in the same location helps users develop spatial memory and trust in your site.

**6. Which color combination offers the best readability?**
a) Light gray text on white
*b) Dark purple text on white*
c) Yellow text on light blue
d) Red text on green

💡 **Background:** High luminance contrast ensures readability for all users, especially low-vision users.
🧠 **Feedback:** *Dark text on light backgrounds* provides strong contrast. Avoid low-contrast or conflicting color pairs like red–green, which are problematic for color blindness.
