06 · Mobile-first responsive patterns

Responsive layout

Resize the browser. CSS Grid changes the layout at 720 px, while Flexbox wraps buttons as needed. All examples are designed to reflow without horizontal scrolling.

Grid panel A

Mobile: stacked. Wider screens: two columns.

CSS Grid

Grid panel B

Content determines its height; no fixed card height is required.

Mobile first

Responsive CSS refresher

/* Mobile first: one column by default. */
.demo-layout {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

/* At 720px and above, show two equal columns. */
@media (min-width: 720px) {
  .demo-layout {
    grid-template-columns: 1fr 1fr;
  }
}

/* A flexible row wraps instead of overflowing. */
.actions {
  display: flex;
  flex-wrap: wrap;
  gap: .75rem;
}

Try browser widths of 375 px, 768 px and 1280 px, then zoom to 200%.

07 · Live token inspector

Inspect the computed values

This table reads the actual CSS custom properties currently applied to the page. Switch themes to compare how semantic tokens change while foundation tokens remain stable.

Light theme
TokenComputed valuePreview

Foundation → semantic → component

/* Foundation: a specific reusable colour */
--blue-500: #004780;

/* Semantic: what the colour is for */
--primary: var(--blue-500);
--on-primary: #ffffff;

/* Component: consumes semantic roles */
.btn-primary {
  background: var(--primary);
  color: var(--on-primary);
}

The prototype's light-theme --primary uses the same HEX value as --blue-500. A literal or an alias can be used; the alias makes the relationship more explicit.
